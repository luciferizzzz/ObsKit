## ✨ Overview

Templates are **markdown skeletons** stored in `templates/`. They give notes a consistent structure and are filled two ways:

1. **Data placeholders** (`{{key}}`) — replaced with title, date, time, folder, etc.
2. **AI placeholders** (`{{ai:instruction}}`) — generated by the AI assistant.

---

## 🛠️ Using templates

### Create a note from a template

```bash
obs new <folder> <title> -t <template>
```

```bash
obs new Notes "Meeting with Team" -t meeting
obs new Code "Arrays" -t js
```

### Generate a note with AI and a template

```bash
obs ai "<prompt>" --template <name> [-t "<title>" -f "<folder>"]
```

```bash
obs ai "Q3 launch plan" --template project -t "Q3 Launch"
```

### List and preview templates

```bash
obs template --list
obs template --preview project
```

## 🔑 Placeholder system

Placeholders come in two forms:

| Placeholder | Example | Behavior |
|-------------|---------|----------|
| Data | `{{title}}` | Replaced with a value (title, date, …) |
| AI | `{{ai:Write a summary}}` | Filled by the AI when using `obs ai --template` |

**Processing order:**

1. Data placeholders are replaced first.
2. AI placeholders are extracted and filled by the AI.
3. Unknown `{{key}}` placeholders are left as-is for manual filling.

---

## 🧾 Template variables

Available **data placeholders** (from `getTemplateData()`):

| Placeholder | Description | Example |
|-------------|-------------|---------|
| `{{title}}` | Note title | `Learning Rust` |
| `{{folder}}` | Destination folder | `Notes` |
| `{{date}}` | Today's date (Indonesian format) | `06-08-2026` |
| `{{time}}` | Current time (Indonesian format) | `14.32` |
| `{{datetime}}` | Date + time | `2026-08-06 14:32:05` |
| `{{created}}` | ISO creation timestamp | `2026-08-06T07:32:05.000Z` |
| `{{updated}}` | ISO last-updated timestamp (same as `{{created}}` on creation) | `2026-08-06T07:32:05.000Z` |
| `{{day}}` | Day of the week | `Kamis` |
| `{{month}}` | Month name | `Agustus` |
| `{{year}}` | 4-digit year | `2026` |

**Custom fields** — built-in templates also use fields like `{{penulis}}`, `{{rilis}}`,
`{{genre}}`, `{{isbn}}`, `{{status}}`, `{{tags}}`, `{{peserta}}`, `{{role}}`, `{{email}}`,
`{{telepon}}`, `{{linkedin}}`, `{{mood}}`. These are left for you to fill manually.

> **v1.5.1 (Better Templates):** every built-in template now shares one standard metadata
> line — `**Tanggal:** {{date}} · **Folder:** {{folder}} · **Dibuat:** {{created}} ·
> **Diperbarui:** {{updated}}` — plus a consistent heading structure.

## 🤖 AI-aware placeholders

Written as **`{{ai:<instruction>}}`**:

```markdown
{{ai:Deskripsi singkat tentang project ini}}
```

When you run `obs ai --template <name>`:

1. Data placeholders are replaced.
2. Every `{{ai:...}}` block is extracted.
3. The AI fills each block (progress: `[1/3] ...`).
4. Blocks are replaced with the generated markdown.

```markdown
## Deskripsi

{{ai:Deskripsi singkat tentang project ini}}
```

becomes:

```markdown
## Deskripsi

Project ini bertujuan untuk membangun aplikasi catatan berbasis terminal yang ringan...
```

> Data placeholders inside an AI instruction are replaced **first**, so the AI knows the topic (e.g. `Jelaskan konsep CSS {{title}}`).

# 🛠️ Custom Templates

Creating your own template takes **two steps**:

1. Add a file to `templates/` — e.g. `templates/recipe.md`.
2. Use it with `-t recipe`.

```bash
obs new Food "Nasi Goreng" -t recipe
obs ai "Resep nasi goreng" --template recipe -t "Nasi Goreng Spesial"
```

> Template names are the filename without `.md`: `recipe`, not `recipe.md`.

**Example — `templates/recipe.md`**

```markdown
# {{title}}

**Tanggal:** {{date}} · **Folder:** {{folder}} · **Dibuat:** {{created}} · **Diperbarui:** {{updated}}

---

## Bahan
{{ai:Daftar bahan-bahan yang dibutuhkan, berupa bullet points}}

## Cara Membuat
{{ai:Langkah-langkah memasak secara urut dan jelas, berupa numbered list}}

## Tips
-
```

**Result:**

```markdown
# Nasi Goreng Ayam

**Tanggal:** 06-08-2026 · **Folder:** AI · **Dibuat:** 2026-08-06T07:32:05.000Z · **Diperbarui:** 2026-08-06T07:32:05.000Z

---

## Bahan
- 2 piring nasi putih
- 1 dada ayam, potong kecil
- ...

## Cara Membuat
1. Tumis bawang putih hingga harum...
2. Masukkan ayam, masak hingga matang...
3. ...

## Tips
-
```

# ✅ Best Practices

- **Use the standard metadata line** — `**Tanggal:** {{date}} · **Folder:** {{folder}} · **Dibuat:** {{created}} · **Diperbarui:** {{updated}}` — so every note looks the same.
- **Use data placeholders for everything repetitive** — title, date, folder.
- **Use AI placeholders for content you want generated** — summaries, lists, decisions.
- **Keep AI instructions specific** — they become the prompt.
- **Reference `{{title}}` in AI instructions** — the AI then knows the topic.
- **Leave sections blank with `-`** — easy to fill later in Obsidian.
- **Name templates with lowercase words** — `meeting`, `project`, `recipe`.
- **Test both modes** — `obs new -t` (data only) and `obs ai --template` (AI-filled).
